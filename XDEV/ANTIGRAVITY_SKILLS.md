## 🛠 CORE SKILLS (The Final Six)

### 1. ✍️ HUMANIZER (Copywriting)
- **Мета:** Гуманізація текстів, видалення AI-штампів.
- **Дія:** Перетворює сухий або пафосний AI-текст на живу, зрозумілу мову.
- **Заборонені слова:** "revolutionize", "leverage", "empower", "unlock potential".

### 2. 🎨 DESIGN-TASTE-FRONTEND (UI Generation)
- **Мета:** Генерація преміального UI-коду.
- **Дія:** Створює компоненти та сторінки в стилях **Blossom (Light Air)** або **Studio (Brutal Dark)**.
- **Фокус:** Bento-сітки, Mica (glassmorphism), ідеальна типографіка.

### 3. 🚀 EMIL-DESIGN-ENG (Animations)
- **Мета:** Анімації та мікро-взаємодії.
- **Дія:** Додає "життя" в інтерфейс через `Framer Motion`.
- **Фокус:** Плавні транзиції, тактильний відгук, `layoutId` анімації.

### 4. 💎 IMPECCABLE (Design Audit)
- **Мета:** Контроль якості дизайну.
- **Дія:** Проводить аудит перед фіналізацією.
- **Фокус:** Відступи, контраст, консистентність, anti-pattern detection.

### 5. 🔍 CODE-REVIEWER (Code Quality)
- **Мета:** Безпека та чистота коду.
- **Дія:** Рецензує код на відповідність `AI_DEVELOPER.md`.
- **Фокус:** TypeScript strict, RLS check, TanStack Query patterns.

### 6. 🏗️ SENIOR-FRONTEND (Implementation)
- **Мета:** Архітектура та продуктивність.
- **Дія:** Реалізує складну логіку Next.js / React.
- **Фокус:** SSR/ISR, Server Actions, TanStack Query optimization.
