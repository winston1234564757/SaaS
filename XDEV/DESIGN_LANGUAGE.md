## Суть: два блоки

Кожна поверхня будується з **темних блоків** (герої) і **світлих блоків** (тіло). Це не про колір — про **роль**. Темний = обкладинка журналу; світлий = сторінка під нею.

```
┌─────────────────────────┐
│ ▓▓ ТЕМНИЙ БЛОК (герой) ▓▓ │  ← одна домінанта, драма, editorial
├─────────────────────────┤
│  Світлий блок (тіло)     │  ← служить герою, hairline, тихо
│  Світлий блок (тіло)     │
└─────────────────────────┘
```

---

## ⬛ Закон темного блоку

> Джерело: WORKFLOW.md §«Принцип темного блоку» (M-ANL-01). Тут — канон.

1. **Проектуй з концепту, з нуля. НЕ ретрофіть.** Спочатку — що ця секція ТАКЕ концептуально (метафора: «досьє», «чек», «P&L», «ритм бізнесу»). Потім композиція.
2. **Асиметрична ієрархія + драма.** Один **герой** (домінанта — велике число / ім'я / метрика) + диференційований решток. Пряма вимога PRODUCT.md anti-ref #1.
3. **Маркер провалу = рівномірність.** N рівних барів / N однакових карток → ретрофіт, переробити. Рівність = дитсадок.
4. **Рендер власними очима ДО founder.** Концепт → композиція → Playwright headless на мок-прев'ю-роут поза auth → самокритика проти цих законів → показ лише сильного варіанту.
5. **«Сміливо» ≠ «темно».** Темний блок = еталон ЯКОСТІ ПРОЦЕСУ, не палітра. Драма можлива й на світлому (типографіка, ієрархія, hairline, домінантні числа).

**Реалізація:** `<EditorialCover>` (`ui/EditorialCover.tsx`) — темний slate-shell на `--cover-bg`. Один герой на поверхню.

## ⬜ Закон білого блоку (новий)

> Світлий блок = «тіло/чек» до темної «обкладинки». **Служить, не конкурує.**

1. **Підпорядкованість.** На поверхні ОДИН темний герой. Світлих блоків багато, але жоден не бореться з героєм за увагу — вони тихі й функціональні.
2. **Hairline-структура.** Тонкі межі (`border-border`), пунктир-роздільники, `bento-card` без важких тіней. **Нуль вкладених карток** (картка в картці = завжди помилка).
3. **Диференціація всередині.** Навіть у списку — свіжий елемент багатший (featured-рядок), старіші компактні. Ніколи N ідентичних рядків. Той самий бан рівномірності.
4. **Тихий токен-рамп.** Головне = `text-foreground`; другорядне = `text-text-sub` (#475569, 5.9:1 на periwinkle). **Заборонено** `text-muted-foreground`/`/60` на світлому фоні (2.76:1 — провал). Плейсхолдери — теж `text-text-sub`.
5. **Числа й імена.** Числа = `.metric-value` (tabular Geist). Імена/дати = `.heading-serif` (Cormorant) — **лише з літерами**; чисті цифри в Cormorant рендеряться oldstyle («18»→«I8»), для них завжди `.metric-value`.

**Реалізація:** `<Section>` (`ui/Section.tsx`) — hairline-хедер (тихий eyebrow + опційна дія) + слот диференційованого тіла.

## On-dark контраст-рамп (текст на темній обкладинці)

Retention/status-хекси відтюнено під СВІТЛИЙ фон — на #0F172A вони провалюють. На темному:

| Роль | Клас | Контраст на #0F172A |
|------|------|---------------------|
| Головне | `text-white` | 15+ |
| Другорядне | `text-white/80` · `/70` | 8+ |
| Найтихіше (дрібний текст) | `text-white/55` | **6.0** (мін. для 10px) |
| Success | `text-emerald-200` (bg `emerald-400/12`) | 11+ |
| Teal | `text-teal-200` | 11+ |
| Warning | `text-amber-200` (bg `amber-300/15`) | 9+ |
| Danger | `text-rose-200` (bg `rose-400/15`) | 12+ |
| Info | `text-indigo-200` (bg `indigo-400/15`) | 8+ |

> ⚠️ `text-white/45` = 4.46 — **провал** для дрібного тексту. Мінімум `/55`.
> Завжди перевіряй пари через `mcp__a11y__get-color-contrast`.

## Токени (`globals.css`)

- `--cover-bg` — `linear-gradient(157deg,#1E293B,#0F172A,#0B1220)`. Фіксований slate: темний блок лишається темним у будь-якій темі.
- `--cover-shadow` — тінь обкладинки.
- `.editorial-cover` — клас-shell (bg + radius + shadow + white text).
- `--card-radius: 24px` (картки/обкладинки) · `--button-radius: 100px` (лишається пілам/чіпам, НЕ прямокутним кнопкам) · `--text-secondary` = `text-text-sub`.

## Кіт примітивів (`src/components/ui/`)

> Історично весь застосунок хендролив кнопки/картки повз кіт (кіт був мертвий) — корінь «6/10 всюди». Тепер кіт канонічний. **Нова/редизайнена робота юзає кіт; старе мігрує опортуністично (по-екранно).**

| Примітив | Роль | Рецепт |
|----------|------|--------|
| `EditorialCover` | Темний блок-герой | `<EditorialCover glowColor={hex}>…</EditorialCover>` — один на поверхню |
| `Section` | Білий блок-тіло | `<Section title="…" icon={I} action={…}>…</Section>` |
| `Button` | Дія | `primary` slate-домінант (одна) · `secondary` hairline · `ghost` тихий · `danger`. Sentence-case, rounded-xl, tactile |
| `Badge` | Статус-піл | `surface="light"` (periwinkle) або `"dark"` (на обкладинці) · variant success/warning/error/info |
| `Sheet` | Модалка/шторка | `srTitle` коли обкладинка володіє ідентичністю (без дубля заголовка) |
| `Input`, `Card`, `DropdownMenu`, `Tooltip` | — | Мігрувати під мову у своїх фазах розкату |

**Еталон реалізації:** `ClientDossierHero` + `ClientDetailSheet` + `BookingDetailsModal` band (C-CLI-01).

**Видалено:** `BentoCard` (був мертвий + буквально заборонений «hero-metric template» + «identical card grids»).

## Абсолютні бани (з impeccable + PRODUCT.md)

- Однакові повторювані bento-картки (icon+велика цифра+статус) — anti-ref #1.
- Side-stripe borders (`border-left` як акцент) → колір на іконці-чіпі.
- Gradient text (`background-clip:text`).
- Glassmorphism як декор (лише де виділяє глибину).
- Hero-metric template (велике число + дрібний лейбл + сателіти + градієнт).
- Tiny uppercase tracked eyebrow над КОЖНОЮ секцією; numbered markers 01/02/03 як скафолд.
- Emoji в UI (No-Emoji policy) → Lucide-іконки.
- `font-black` / `font-thin` (заборонені ваги).
