## ▶ NEXT: `M-SVC-01` — Послуги: синхронізація даних (P0)

**Тип:** P0 BUGFIX (критичний блокер) · **Скіли:** `diagnose` → `senior-backend` → `code-review`

**Проблема:** Аналітика і статистика по послугах не передається на бекенд / не відображається. Повністю зламаний пайплайн даних.

**Підхід (diagnose-first — НЕ одразу фіксити):**
1. Відтворити: зайти на `/dashboard/services`, відкрити аналітику послуги → зафіксувати, що саме порожнє/не зберігається.
2. Локалізувати розрив пайплайну. Кандидати на перевірку:
   - `src/components/master/services/ServicesPage.tsx`, `ServiceCard.tsx`, `ServiceEditor.tsx`
   - Server actions послуг (де агрегується статистика візитів/виручки по послузі)
   - Аналітика, що споживає ці дані: `master/analytics/AnalyticsPage.tsx` (вкладки), `TopServicesWidget.tsx`
   - Чи пишуться дані при `completeBooking` (зв'язок booking → service stats)
3. Гіпотеза → інструментувати (лог/SQL через `mcp__supabase__execute_sql`) → підтвердити root cause.
4. Фікс на рівні, де реально розрив (не симптом).
5. Regression: переконатись, що дані тепер ідуть end-to-end.

**Acceptance criteria:**
- [ ] Root cause задокументовано (де саме рвався пайплайн)
- [ ] Статистика по послугах відображається коректно (виручка/к-сть записів/тренд)
- [ ] Дані зберігаються на бекенд при відповідній дії
- [ ] TSC: 0 | Build: clean
