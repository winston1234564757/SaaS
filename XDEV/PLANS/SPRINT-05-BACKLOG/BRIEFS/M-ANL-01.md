## Калібрування наміру (з brainstorming)
Founder відкинув гіпотезу «забагато табів» (IA не біль). Реальні **три осі болю**:
- **(а)** аналітика гарна, але **не дає рішень** — числа без «що з цим робити»;
- **(б)** **виглядає дешево** — візуал не тримає планку Frost / ціну Pro;
- **(в)** **порожньо для новачка** — 0 даних = глухий кут.

**Напрям:** змішаний — glanceable верх рішень + drill нижче/в табах.
**Scope сесії:** каркас (shell) + таб **Огляд** доведений до фіналу. Решта 6 табів — НЕ цієї сесії (premium протече в них через спільні примітиви — бонус, без редизайну їх вмісту).

### Візуальний діагноз зі скрінів (SCREENS/image copy 2,3.png · Pro · desktop)
Домінантний гріх — **порожнеча + нульова щільність на десктопі**, НЕ кольори:
1. **Гігантські напівпорожні картки.** `HeroStory` («ОГЛЯД») = одне речення в картці ~250px, 70% мертвого простору. Інсайт один, губиться.
2. **Хедер-картка роздута** — 5 пілюль періоду + навігатор місяця займають пів-екрана.
3. **KPI пласкі** — числа без Δ/стрілок/тренду (вісь «а» підтверджена візуально).
4. **Десктоп = розтягнута мобільна колонка** — KPI 4-в-ряд, решта full-width одноколонкою з велетенськими gap. **Немає bento-grid** — головний візуальний борг (вісь «б»).
5. **Periwinkle-на-periwinkle**, заголовки секцій = крихітний сірий капс → нульова ієрархія.
6. **Баг копірайту/формату** в `SmartPricingOptimizer`: «+83,200/міс у субота» — кома замість пробілу в ₴ + «суботу».
- Дата-шар: `useAnalytics` (summary/monthStats/topServices/topProducts/retention/bento) + `useAnalyticsExtras` (Pro мега-RPC: pricing_uplift, anomaly, ltv_concentration, business_health, cohort, occupancy, pairing).
- Усі 7 табів юзають `BentoCell` (35 входжень) — **спільні примітиви підтверджено**.

## Факти, закриті grilling (не припущення)
- **Δ дані вже є:** `useAnalytics` тягне `prevPeriod` (`getPrevPeriodRange`), рахує `avgCheck.delta`. Prev-period рядки в відповіді → Δ для виручки/к-сті записів виводиться **без дотику дата-шару**. `isPro`-gated → Δ природно Pro-only.
- **Інсайти вже існують** у `storiesList` — їх не треба вигадувати, треба **підняти нагору**.

## Ціль (дизайн-напрям)
**«Insight-first shell» + ЩІЛЬНІСТЬ** — інтерпретація поверх наявних даних + ліквідація порожнечі через десктоп-bento. UI-редизайн веде, Δ-логіка вторинна.

1. **Розчистити майданчик (C1):** механічно винести з оркестратора в окремі файли — 4 inline-хуки (→ `useAnalyticsMarketing.ts` чи окремі), `ServiceRow`, `ClientSheetById`. Нуль зміни логіки, tsc між кроками.
2. **Десктоп bento-grid (новий, з аналізу скрінів — головний борг «б»):** прибрати розтягнуту одноколонку. Верх Огляду → щільна сітка (KPI + інсайти + графік + топи в bento-розкладці), не full-width стопка з gap. Мобільний лишається колонкою.
3. **Premium на рівні примітивів:** підняти `BentoCell`, section-header (зараз крихітний сірий капс → читабельна ієрархія), KPI-картки. Протікає в усі 7 табів. Лікує (б) системно.
4. **KPI з Δ + HeroStory ущільнити (C2):** KPI з Δ-до-минулого-періоду + знак/колір тренду (Pro). `HeroStory` з одного-речення-в-порожнечі → **кілька інсайтів у щільному layout** як головний сигнал-з-дією. Лікує (а). Нуль вигаданих інсайтів — кожен мапиться на реальне поле.
5. **Empty-state новачка (C4):** замість одного `EmptyCell` — activation-блок: опис-цінності + кроки. **Нуль фейкових чисел/графіків.**
6. **Starter-цінність:** Огляд корисний для не-Pro (виручка, топ-послуги/клієнти, експорт) без Δ.
7. **Фікс копірайту/формату** в `SmartPricingOptimizer` (₴-формат через `formatPrice`, «суботу») — попутно, бо файл і так у зоні Огляду.
