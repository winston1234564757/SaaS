## Пріоритет 0 — Спільні примітиви (фіксять баги в УСІХ секціях одразу)

1. **`shared/CountUp.tsx`** — число мусить бути видиме за замовчуванням.
   - `text` стартує з фінального значення `to` (SSR/headless/reduced показують готове число).
   - Анімація 0→to запускається лише коли `!shouldReduce && inView`; якщо observer не спрацював — лишається фінальне число.
   - Прибрати `initial opacity:0`-гейт (або default opacity:1). **Ніколи не ship 0/невидиме.**

2. **`LandingSplitHeading.tsx`** — прибрати клипінг + гейт.
   - Прибрати per-word `overflow:hidden` mask-reveal (він ріже кириличні виносні при `leading-[0.9]`) → замінити на fade/tint-reveal без обрізання, АБО mask із достатнім вертикальним запасом (padding + від'ємний margin).
   - Default-visible: слова видимі й без `inView`; reveal лише підсилює. `shouldReduce` → миттєво.
   - Це прибирає клипінг «вже сьогодні / заповнить / номер / записом» по всіх секціях.
