# G-LAND-02 — Лендинг: мобільна шапка, компактна CTA + відступи 10px

**Тип:** BUGFIX (mobile responsive)
**Пріоритет:** P0
**Статус:** DONE
**Спеціаліст-скіли:** `design-taste-frontend` (+ `impeccable`, `mcp__a11y`, `humanizer` якщо змінюємо лейбл)

## Поточний стан
Файл: `src/components/landing/LandingNav.tsx` (рядки 60-81 — центральна CTA).
- Шапка `fixed`, 3-колонковий грід `1fr auto 1fr`, ширина `min(720px, calc(100vw - 32px))`; `header px-4 pt-5`, `nav px-5 py-3 rounded-full`.
- Зліва: лого `bookit.`
- Центр: CTA `Спробувати безкоштовно` + кружок зі стрілкою. `text-sm pl-5 pr-2.5 py-2`, `whiteSpace: nowrap`.
- Праворуч: `Увійти` (`hidden sm:block` — на моб. прихований) + гамбургер `size-9`.

> ⚠ Скріншот не надано — аналіз із коду. Якщо є скрін реального переповнення — додай, уточнить діагноз.

## Ціль / Root cause (гіпотеза)
На вузькому моб. (~360px) внутрішня ширина шапки ≈ 360 − 32 (зовн.) − 40 (`px-5`) ≈ 288px.
CTA з повним текстом + `nowrap` + стрілка ≈ 180px, лого ≈ 80px, гамбургер 36px → сума > доступне → CTA впритул до сусідів, немає чистого відступу по краях.
**Фікс:** компактніша CTA на моб. + чіткий ~10px відступ по краях. Desktop (`sm:` ≥640px) не чіпати.

## Файли, які чіпаю
- `src/components/landing/LandingNav.tsx` — тільки мобільні класи центральної CTA (і, можливо, `px` шапки/nav). Один файл.

## Ризики / що може зламатись
- Грід `1fr auto 1fr` центрує CTA — зменшення CTA зрушує центрування; перевірити, що лого/гамбургер не стрибають.
- Не зламати desktop (≥640px) — усі зміни `sm:`-gated.
- **Конфлікт із a11y:** зараз CTA по висоті `py-2 + text-sm` ≈ 36px — це НИЖЧЕ за обов'язкові 44px (правило touch-target). "Компактніше" має бути по ШИРИНІ (менше тексту/горизонт. padding), а висоту треба ПІДНЯТИ до ≥44px, не опускати.
- `focusRing` і `aria` зберегти.

## Acceptance criteria
- [ ] На моб. CTA не торкається країв, чистий ~10px відступ по краях
- [ ] Touch target CTA ≥ 44px висота (a11y)
- [ ] Desktop вигляд незмінний
- [ ] TSC 0 / build clean

## Відкриті питання до тебе
1. **Компактність на моб.:** (a) лишити повний текст `Спробувати безкоштовно`, зменшити горизонт. padding; (b) скоротити лейбл на моб. (напр. `Почати`); (c) лишити текст, прибрати кружок-стрілку на моб.
2. **"10px по краях":** (a) шапка 10px від країв екрана (зараз 16px); (b) внутрішній padding кнопки ~10px; (c) обидва — єдиний 10px ритм.
