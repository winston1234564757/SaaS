## Концепт: «Досьє клієнта» (founder обрав)

Одна драматична **темна обкладинка-герой**, що зрощує *хто ця людина* + *наскільки цінна* + *чи є червоний прапорець*, і **диференційований решток** нижче. Асиметрія замість стосу рівних карток.

### Hero — темна slate-обкладинка (`var(--accent)` #0F172A)
- Аватар (serif-ініціал) + **ім'я Cormorant serif = єдина домінанта** + телефон (tap-to-call).
- Статус-рядок: retention-піл + VIP + амбасадор (окремим рядком, бо довгий лейбл).
- **Зрощення цінності (лише картка клієнта):** total_spent великим tabular-числом + ранг «#3 з 76» + смуга + каденс «раз на 3 тижні». Це фьюжн старого блоку «Цінність клієнта» В hero.
- 🔴 **Сигнал алергії:** якщо `medical_notes` є → червоний чіп-прапорець «Алергія» прямо в герої (майстер бачить одразу). Відповідь founder Q3.
- Retention-glow на темному (reuse `statusGlow`, тон під темний фон).

### Диференційований решток (світлі секції під hero)
1. **Останні записи** — свіжий запис = багатший рядок (більший, послуга+ціна+статус), старіші = компактні. НЕ N рівних рядків.
2. **Особисті мітки** — хмара чіпів (легітимна рівномірність, як фото-грід) + додавання. Без змін логіки.
3. **Безпека та здоров'я** — тихий **розкривний** блок (сигнал уже в герої): згорнутий рядок → tap → 2 textarea. Автозбереження недоторкане.
4. **Приватні нотатки** — textarea (без змін логіки, полиш візуалу).
5. **Дії** — churn-нагадування / VIP / архів; диференційовано (головна дія помітна, деструктив тихий).

### Спільність із карткою запису (founder: «записи теж, в одному стилі»)
**«Один стиль» = обидві модалки відкриваються темною editorial-обкладинкою** (спільна візуальна мова). Суб'єкт різний (founder підтвердив):
- **Картка клієнта:** обкладинка = КЛІЄНТ (ім'я serif + зрощення цінності + сигнал алергії + retention/VIP/амбасадор).
- **Картка запису:** обкладинка = ЗАПИС — конвертуємо наявний чек-hero-band (M-BOOK-05, зараз світлий glow) → у **темну slate-обкладинку** (дата serif + час + статус + source-піл). Тіло чека (позиції+total) лишається світлим. Клієнт = полірована **інлайн-смуга** нижче (не краде роль героя-запису).

Реалізація: спільний shell `CoverHero` (темний slate band: glow, padding, serif-slot, meta-slots) → обидві модалки юзають з різним контентом. `ClientIdentityHeader` лишається як світла інлайн-смуга клієнта (полиш) для картки запису.

`ClientStatChips` — рестайл під нову систему (спільний). У картці клієнта total_spent їде в hero → чіпи стають вторинними: **візити / сер.чек / останній візит** (без дублю). Картка запису лишає свої 3 чіпи.

🔴 **Зачіпаємо M-BOOK-05:** чек-hero-band стає темним. Ризик регресії нещодавно зданого — рендер картки запису власними очима обов'язковий.

## Self-grill (дірки, зловлені ПЕРЕД кодом → резолюції)

1. **🔴 CRITICAL — темна обкладинка ламає картку запису.** У `BookingDetailsModal` header стоїть ПЕРШИМ, одразу під ним — чек із власним світлим serif-героєм (M-BOOK-05). Темна обкладинка згори = два герої, темний краде фокус у чека. → **`variant` (cover/inline)**: картка запису лишається зі світлою inline-смугою, чек = зірка.
2. **Читабельність темного на мобілці (5-хв перерва).** Slate + світлий текст, менше відблиску при швидкому погляді. → retention/health/value кольори — **світлі тони (emerald-300/rose-300/amber-300 діапазон) ≥4.5:1 на slate**, НЕ світлотемні retention-хекси (`#15803D` etc. відтюнено під СВІТЛИЙ фон, на темному провалять). Перевірка a11y MCP.
3. **Cormorant цифри.** `metric-value`/tabular для чисел (₴, ранг), serif лише для імені (урок M-ANL-04: Cormorant «18»→«I8» oldstyle).
4. **Ергономіка інлайн-редагування.** Усе редагування лишається у СВІТЛИХ секціях; hero — display-only. Health розкривний, але автозбереження/дебаунс недоторкані.
5. **Edge-кейси (всі вже покриті в коді — переносимо):** без акаунта (`client_id=null`) → мітки/health/VIP disabled з поясненням; без записів → empty-стан; довге ім'я → serif `text-balance`+clamp на темному; без рангу (`totalClients≤1`) → ховаємо ранг+смугу, каденс лишається якщо ≥2 записи; без даних амбасадора → без бейджа.
6. **Дубль total_spent** (hero + чіп «Витрачено») → прибрати з чіпів картки клієнта.
