## Розширення скоупу (founder, 2026-06-28): хаб-шелл

Редизайн флеш-контенту оголив дві проблеми у шапці Revenue Hub (`RevenueHubClient.tsx`):
1. **Twin-card:** шапка-хаб і новий флеш-hero обидві «іконка + serif-заголовок + сірий підзаголовок» → дублювання (anti-ref PRODUCT).
2. **Tab overflow:** пілюлі `flex-1 px-5` + іконка + текст переносились на 2 рядки / вилазили за картку на мобільному.

**Рішення (founder QA: текст-онлі таби на мобільному):**
- Шапку понижено до тихої навігації: іконка size-9 `bg-accent-light`, sans-заголовок (не serif-hero), підзаголовок `hidden lg:block` (на мобільному прибрано → де-твін + місце).
- Таб-бар: текст-онлі на мобільному (`whitespace-nowrap`, px-5→px-3), іконки `hidden lg:block` (десктоп вертикальна навігація). Slate-active + `layoutId` збережено.

## Before (поточний стан)

Стек рівноважних bento-карток згори вниз: хедер (іконка + 2 vanity-метрики «Активних / За місяць») → Starter-прогрес ліміту → авто-flash тогл → форма створення (послуга → дата → слоти → знижка → тривалість → прев'ю ціни → CTA) → список активних / empty.

**Проблеми (чесний критик):**
1. **Off-theme хардкод-хекси** (`#D4935A`, `#5C9E7A`, `#2D6A4A`, `#F0E4DF`) — залишки Blossom-епохи у Frost-only світі.
2. **Помаранчевий усюди** (іконка, метрики, чіпи, тривалість, CTA, активні) → значення «гарячого» сигналу стерте. Суперечить quietly-premium Frost.
3. **Рівний стек карток без ієрархії** — «інструмент заробітку» не має фокуса (anti-ref PRODUCT: bento overuse).
4. **Меседж механічний** («Заповни вільне вікно — сповісти клієнтів») — процес, не цінність.
5. **`timeUntil()` написана, але не використовується** — активні акції показують лише дату·ціну, без живого відліку.

## Дизайн-напрям (APPROVED через brainstorming + craft)

**Відчуття:** вигода/заробіток (головне) · терміновість = текстура (таймери) · контроль = структура (чисті кроки).
**Колір:** база Frost (slate `--accent` #0F172A на лавандовому склі `--surface`), помаранчевий `--warning` #B45309 — ЛИШЕ точковий «гарячий» сигнал.
**Скоуп:** весь таб, БЕЗ глибокої аналітики (то M-REV-03). Нудж заробітку = легкий, прогноз вперед (не статистика).

### Ієрархія (зверху вниз)
1. **Hero — меседж вигоди** (єдиний Committed-момент): редакційний serif-заголовок + підзаголовок цінності. Єдина амбер-іскра тут. Активний стан вплетений (N акцій працює). БЕЗ hero-metric шаблону (банлист impeccable).
2. **Форма створення — серце** (control = структура): чисті кроки. Грошовий нудж у прев'ю.
3. **Активні акції — текстура терміновості:** живий таймер `timeUntil(expires_at)` на кожній. Один спільний інтервал 1/хв (не per-card). Expired-стан inline якщо таймер=0 а акція ще в списку.
4. **Ліміт Starter + авто-flash + paywall — тихі допоміжні:** приглушити, на токени.

### Колірний мепінг (прибирання)
- Усі хардкод-хекси → токени теми (`bg-primary`, `text-foreground`, `--surface`, `--warning`, `--accent-light`).
- **CTA «Запустити акцію» → slate `bg-primary`, НЕ помаранчевий** (найвідчутніша зміна, founder ОК).
- `--warning` → лише: таймери активних, іскра в hero, ліміт-на-межі (≥3/5).
- Selected-стани (слот/знижка/тривалість) → accent/surface-вибір як таб-пілюлі, не суцільний помаранч.

### Bolder vs Quieter
- **Bolder:** hero-меседж · грошове прев'ю · таймери активних.
- **Quieter:** помаранчевий → точково · vanity-метрики → у бік вигоди · авто-flash/ліміт → спокійні · рівний стек → ієрархія.

## Copy (через humanizer ✓)

| Призначення | Фінал |
|---|---|
| Hero title | Вільне вікно? Заповни знижкою. |
| Hero subtitle | Порожній слот не заробляє. Клієнти побачать акцію одразу. |

Рішення founder (grill QA): грошове прев'ю = **виручка** «+X₴ за порожній слот», без слова «прибуток» (собівартість не врахована, даних немає → не вводимо в оману).
