## Before (звірено по коду)
`PricingHero` тягне 4 роботи в одній картці:
1. Обіцянка — `ArrowUpDown` + serif «Ціни, що працюють без тебе» + subtitle + active-count бейдж.
2. Доказ — conditional рядок `showEarned`/`showSlots` (зароблено ₴ + врятовані слоти, COOL tint).
3. **Механіка — 3 тап-чіпи** `Стекінг` / `Max -30%` / `Max +50%` (грід) + `AnimatePresence` карет-поповер з реченням на кожен (стейт `activeChip`, математика `caretLeft`).

Проблема: доказ і чіпи конкурують. Механіка (ліміти −30/+50, накладання) — **довідка-виноска**, схована за тапом, жаргонними ярликами. Ліміти вже демонструються живими `PreviewRow` («500 → X») і картками правил нижче. Ніхто не тапає чіпи, щоб прочитати правила гри.

## Напрям (committed craft): hero = обіцянка + доказ, механіка = виноска

Три рівні гучності, зверху вниз:
```
[↕] Ціни, що працюють без тебе          [2 активні]   ← обіцянка (гучно, serif) — БЕЗ ЗМІН
    Знижки заповнюють тихі вікна…

┌ ↗ Динамічні ціни додали +340₴ · 5 слотів ┐          ← доказ (COOL tint, conditional) — БЕЗ ЗМІН
└──────────────────────────────────────────┘
────────────────────────────────────────────         ← hairline (border-t)
⊕ складаються   ↓ до −30%   ↑ до +50%                 ← гарантії (тихо, завжди видно)
```

**Що змінюється (це і є distill):**
- **3 тап-чіпи + карет-поповер → один тихий рядок-виноска**, завжди видимий, відділений hairline border-top. Видаляється: `INFO_CHIPS` грід-кнопки (3 бордери), стейт `activeChip`, `AnimatePresence` поповер, `caretLeft`, жаргон-ярлики.
- ~40 рядків JSX → ~8. Менше поверхонь, нуль інтеракції-заради-довідки.
- Людська мова замість механічних термінів: `складаються` / `до −30%` / `до +50%` з дрібними inline-іконками (`Layers` / `TrendingDown` / `TrendingUp`), як спокійна muted-стрічка, не кнопки.

**Не чіпаємо:** header (заголовок+subtitle+бейдж), proof-логіку (`showEarned`/`showSlots`/`showResult`), `AnchoredTooltip` тур (прив'язаний до контейнера hero, не до чіпів — звірено), props компонента, рендер `!isDrawer`.

## Два мікро-рішення (потрібен вибір founder)
1. **Колір виноски:**
   - (A, рекомендую) **монохром-muted** — найчистіший distill, hero тихий; warm/cool колір уже несуть секції нижче.
   - (B) семантичний тінт стрілок: ↓ green (COOL) / ↑ amber (WARM) — краща скануваність + зв'язок із секціями, але трохи більше шуму.
2. **Формулювання guardrail** (через humanizer): варіант «складаються · до −30% · до +50%» vs «складаються, але в межах −30% / +50%» (явніше, що ліміт на суму).

## Ризики
- Контраст виноски: «тихо» ≠ світло-сіре. `text-muted-foreground` у Frost має пройти ≥4.5:1 — перевірю `mcp__a11y` на токені перед білдом.
- Lucide іконки: колір через `className`/wrap-span (не `style`) — конвенція проєкту.
- Втрата повних речень механіки — свідоме відхилення (механіку вчать `PreviewRow` + картки + M-REV-05 overview одразу під hero).
