## Ціль (дизайн-напрям)
Преміум-панель відгуків за патерном M-MKT-06 (de-template + Frost-токени + outcome-ієрархія).

**1. Hero-зріз статистики** (замість 3 однакових карток):
- Головне outcome-число = **середній рейтинг** (велике serif, напр. `4.8`) + ряд зірок + «N відгуків» підпис. Це публічна оцінка майстра — головна цифра.
- Тиха роздільна стрічка вторинних метрик: `Публічні N · Приховані N` (без коробок, як M-MKT-06).

**2. Розподіл рейтингу = фільтр (преміум-хід):** горизонтальна гістограма 5★→1★ (рядок на кожен бал, смуга-частка + count). Кожен рядок — **клікабельна кнопка-фільтр** (`aria-pressed`): тап по «5★» → показати лише 5-зіркові. Об'єднує редизайн + зірковий фільтр в один елемент замість окремого ряду чіпів.

**3. Контроли:**
- Фільтр публікації (Всі/Публічні/Приховані) — лишити, токенізувати.
- Зірковий фільтр — через клікабельні рядки гістограми (multi-select по балах).
- Тогл **«Лише з коментарем»** — відсіює голі оцінки.
- Сортування — сегмент/дропдаун: **Новіші / Старіші / Високий рейтинг / Низький рейтинг**.
- Активні фільтри → dismissible-індикація + «Скинути».

**4. Картки (M-REVW-02):** тіло картки клікабельне → деталь-Sheet. Publish-тогл лишається **sibling-кнопкою** (a11y, не вкладена в клікабельне тіло — патерн M-SHOP-02/M-SVC-03). Хекси → Frost-токени. Коментар у картці line-clamp, повний — у Sheet.

**5. Деталь-Sheet (M-REVW-02):** vaul `BottomSheet` (reuse, НЕ голий framer — IRON RULE) — повний відгук: аватар+ім'я, дата запису, зірки+бал, повний коментар без обрізки, дія публікації/приховання. Дзеркало патерну `BroadcastDetailSheet`/`FlashDealDetailSheet`.
