## Концепт: «Герой дня = наступний запис» (founder обрав)

Одна темна editorial-обкладинка (`EditorialCover`), домінанта якої — **хто наступний і коли**. Дата/час/привітання = тиха підводка НАД домінантою, не конкурує. Наступний запис — зірка, яку майстер зчитує за 3 сек.

### Hero — темна slate-обкладинка (`EditorialCover`, `glowColor` = колір статусу запису)
```
┌─ DARK COVER (editorial-cover) ───────────────┐
│ П'ятниця · 4 липня        12:40   ← тихо /55 │
│ Доброго дня, Вікторе              ← /80      │
│                                              │
│ НАСТУПНИЙ                         ← eyebrow  │
│ Олег М.                    ● 14:30           │  ← домінанта
│ Стрижка + борода · Сьогодні                  │
└──────────────────────────────────────────────┘
```
- **Підводка (тихо):** день+дата (`heading-serif`, лише літери) + час `metric-value` праворуч — обидва `text-white/55..70`, дрібні. Прибрати роль «двох великих чисел».
- **Привітання:** `Доброго [X], [Ім'я]` — `text-white/80`, без `FitText`/`useAdaptiveColor` (фон тепер фіксовано темний → просто on-dark ramp).
- **ДОМІНАНТА — наступний запис:**
  - Ім'я клієнта = `heading-serif` (Cormorant), найбільше (єдина serif-домінанта).
  - Час = `metric-value` великим tabular праворуч + status-dot (світлий тінт).
  - Послуга + коли (Сьогодні/Завтра/дата) = `text-white/55`.
  - Уся обкладинка — `<Link>` на `?bookingId=` (як зараз).
- **Retention/статус-glow:** `glowColor` з кольору статусу (confirmed→emerald, pending→amber), відтон під темний фон.

### Диференційований порожній стан (НЕ рівна карта)
Якщо наступного запису немає (вільний день / кінець дня) → **інша домінанта:** великий тихий стан «Записів попереду немає» + одна дія (`Button primary` → створити запис / маркетинг). Обкладинка лишається темною, домінанта інша. Ніколи не показувати «пусту» hero-card.

### Shell-chrome (полірування до вау + під мову, БЕЗ окремих DS-задач)
- **`FrostMetricsStrip`** → лишається метрик-стрічкою, але поліш до вау + диференціація: прибрати ефект «8 рівних» — головна метрика дня (виручка АБО записи сьогодні) візуально важча за решту; токен-рамп під мову (`text-text-sub`, не tertiary). Механіка тікера/тач-драг недоторкана.
- **`FrostActionsBar` / `QuickActionsWidget`** → на кіт `Button` (`ghost`/`secondary`), tap-feedback лишити.
- **`FrostDivider` + ритм** → hairline `border-border`, вивірити вертикальний ритм відступів.

**Дата-віджети (WeeklyChart, PeakHours, Cancellation, NextFreeDays, Insights, ChannelHealth, TopServices, Earnings, AdaptiveContextStrip) — ПОЗА цією задачею** (власні DS-DASH-02..10). Межа підтверджена founder.

## Self-grill (дірки, зловлені ПЕРЕД кодом → резолюції)

1. **🔴 Дві теми домінанти — «наступний запис» vs «форма дня».** Founder обрав наступний запис → виручка/лічильники НЕ лізуть у домінанту hero, вони лишаються у метрик-стрічці нижче. Уникаємо двох героїв.
2. **Порожній стан = провал у рівномірність?** Ні — порожній стан отримує ВЛАСНУ домінанту (стан+дія), не клон карти. Це диференціація, не рівність.
3. **On-dark контраст.** Status-dot і тінти — світлі (`emerald-200/amber-200/rose-200`), дрібний текст мін `white/55` (6.0). Retention-хекси відтюнено під світле → на slate НЕ юзати. Перевірка `mcp__a11y__get-color-contrast` на всіх станах.
4. **Cormorant цифри.** Ім'я клієнта — serif (літери). Час/дата-числа — `metric-value` tabular (урок «18»→«I8»). Дата-місяць словом («4 липня») — ок для serif, але число дня лишити в metric-value якщо стоїть окремо.
5. **`useAdaptiveColor` / `FitText` більше не потрібні** на фіксованому темному фоні → прибрати залежність (спрощення). Перевірити, чи не юзаються деінде.
6. **`--hero-card-bg` токен** (стара NextBookingRow) — після заміни на `editorial-cover` перевірити, чи не осиротів (grep інші споживачі перед видаленням; НЕ чіпати токен якщо юзається в інших темах).
7. **Tour-кроки.** `data-tour-step={0}`/`data-tour-key="dash-0"` на greeting-обгортці — зберегти на новому hero-контейнері (тур не має зламатись).
8. **Skeleton на темному.** Loading-стан переробити під темну обкладинку (не світлі shimmer-блоки на світлому).
9. **Неділя виключена** (`getDay()===0`) + today>time / tomorrow / date-label — існуюча логіка `nextBooking`, переносимо без змін.
10. **Довге ім'я/послуга** → `text-balance` + clamp на темному.
