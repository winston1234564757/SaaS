## Роль на поверхні
Це **світлий блок-тіло** (`Section`), НЕ другий темний герой — єдиний темний cover поверхні вже є (DS-DASH-01 «Герой дня»). Закон білого блоку: служить, hairline, власна диференціація всередині.

## Before (чому переробляємо)
`WeeklyChartWidget.tsx` — сирий `bento-card` (не кіт-примітив). Хедер: велике число-сума 2rem + delta% + тогл Записи/Дохід. 7 барів heat-рампою на акценті; виділений лише **сьогодні** (accent). Тултіп по кліку, empty-стан.

Слабке під Закон:
- Сирий `bento-card` замість `Section` (не конвергентний до мови).
- 7 барів близькі до «N рівних» — диференційований лише *сьогодні*, а **пік-день не виділений** (втрата асиметрії; найсильніший день тижня = природна зірка, а він тоне).
- Хедер тяжіє до «hero-metric template» (велике число + дрібний лейбл) — тримати як легітимну P&L-домінанту, не як шаблон-кліше.

**Єдиний споживач:** `FrostDashboard` (mobile custom={6} + desktop grid 40/60 з `[&>*]:h-full`). Регресійний ризик локальний, але віджет розтягується по висоті в desktop-гріді → `Section` мусить тримати `h-full flex flex-col`.

## Концепт: «P&L тижня» (founder обрав)
Домінанта = **сума тижня** (велике tabular-число + delta vs минулий тиждень). Бари = ритм під нею, але з **чіткою асиметрією**: пік-день — зірка, сьогодні — маркер позиції, решта тихі.

### Структура (Section-примітив)
```
┌─ Section (світлий, hairline) ───────────────┐
│ ТИЖДЕНЬ  [BarChart2]        [Записи|Дохід]   │  ← Section header: eyebrow + action=тогл
│                                              │
│ 14 900 ₴   +12%              ← домінанта      │
│ vs минулий тиждень                           │
│ ▁ ▃ ▂ ▅ █ ▂ ▁               ← бари            │
│ Пн Вт Ср Чт Пт Сб Нд                         │
└──────────────────────────────────────────────┘
```

### Диференціація барів (розбити «7 рівних»)
- **Пік-день** (max за поточним режимом) = solid `var(--accent)` + значення завжди підписане й жирніше + тонкий маркер (напр. крапка/каре над баром). Це зірка графіка.
- **Сьогодні** (якщо ≠ пік) = маркер ПОЗИЦІЇ, не значення: accent day-label (є) + тонке кільце/підкреслення на барі, але fill лишається heat-рампою. Розведені ролі: пік=значення, сьогодні=позиція, без двозначності «два акценти».
- **Решта днів** = тиха heat-рампа (світліша), щоб пік вигравав. Нижній поріг тримає слабкі дні читабельними (не вицвілими).
- Висота бара лишається первинним сигналом (data-driven), колір підсилює.

### Що зберігаємо без змін логіки

## Self-grill (дірки → резолюції)
1. **Section розтяг по висоті.** Desktop-грід дає `[&>*]:h-full`. `Section` = `bento-card` div без flex-1 → передати `className="h-full flex flex-col"` + `bodyClassName="flex flex-col flex-1"` щоб бари сідали донизу. Перевірити обидва режими (mobile stack + desktop 40/60).
2. **Пік=сьогодні колізія.** Якщо найсильніший день = сьогодні → один бар несе обидві ролі: solid accent (пік) + він і так accent-label. Не дублювати маркери; показати як пік.
3. **Пік у режимі Дохід vs Записи.** `values` вже режим-залежні → `peakIdx` перераховувати per-mode (пік записів ≠ пік доходу). Ок.
4. **Порожній тиждень / усі нулі.** maxVal=1 fallback → без пік-підсвітки, показати empty-рядок «Записів за тиждень ще немає». Не підсвічувати «пік» коли даних нема.
5. **Eyebrow-reflex.** «ТИЖДЕНЬ» — тихий функціональний лейбл модуля (10px text-text-sub), не декоративний landing-eyebrow. Домінанта = число 2rem, не eyebrow. Легітимно на дашборді.
6. **Cormorant цифри.** Сума/значення = `metric-value` tabular (НЕ serif). Serif тут не застосовний (дашборд-числа).
7. **A11y барів.** Кожен бар — `<button aria-label>` + `aria-pressed` (є). Пік-маркер декоративний → `aria-hidden`. Тултіп — не єдине джерело (aria-label несе дані).
8. **`scroll` listener для dismiss тултіпа** — лишити (passive, це не motion-scroll). Не чіпати.
