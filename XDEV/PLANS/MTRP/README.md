## 🚦 Залізне правило виконання

> **VERIFY-BEFORE-DELETE / VERIFY-BEFORE-FIX.**
> План згенеровано сканами 2026-06-02 і він **місцями неточний** (вже знайдено 2 помилки в P0.10 — див. [TRACKER §Plan Corrections](./TRACKER.md#-plan-corrections--new-findings)).

## 🎯 Quick start для нової сесії

```
1. mempalace_status                              (IRON RULE -1)
2. Read XDEV/MAPS/SYSTEM_MAP.md (last 50)        (IRON RULE -1)
3. Read XDEV/PLANS/MTRP/MAP.md                   ← «де я зупинився»
4. Read XDEV/PLANS/MTRP/TRACKER.md               ← наступні ⏳ items
5. mempalace_search "[item keywords]"            (перед рішенням)
6. WORKFLOW.md per-item loop:
   verify importers → fix → tsc → build → log → commit → tracker/map update
7. mempalace_add_drawer (після значущого item)
```
