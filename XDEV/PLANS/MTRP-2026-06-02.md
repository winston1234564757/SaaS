## 5. P0 — BLOCKERS (13 items)

### 5.1 P0.1 — `linkBookingToClient` allows booking hijack

**File:** `src/app/[slug]/actions.ts:12-30`  
**Severity:** CRITICAL P0  
**Category:** Security / Horizontal Privilege Escalation  
**Effort:** 4h

**Current vulnerable code:**
```ts
export async function linkBookingToClient(bookingId: string): Promise<void> {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return;
  
  const admin = createAdminClient();
  await admin.from('bookings')
    .update({ client_id: user.id })
    .eq('id', bookingId)
    .is('client_id', null); // only link if not already linked
}
```

**Attack vector:**
1. Attacker creates phone-based account, gets `user.id`
2. Observes `bookingId` in URL (e.g., `?bookingId=abc-123`)
3. Calls `linkBookingToClient('abc-123')` as different user
4. Booking is now linked to attacker — they cancel/receive notifications

**Solution (Option A: Phone-match verification — recommended MVP):**

```ts
export async function linkBookingToClient(bookingId: string): Promise<void> {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) throw new Error('Not authenticated');
  
  const admin = createAdminClient();
  
  // 1. Fetch booking
  const { data: booking, error } = await admin
    .from('bookings')
    .select('id, client_id, client_phone')
    .eq('id', bookingId)
    .single();
  if (error || !booking) throw new Error('Booking not found');
  if (booking.client_id && booking.client_id !== user.id) {
    throw new Error('Booking already linked to another user');
  }
  if (booking.client_id === user.id) return; // already linked to self
  
  // 2. Verify user's phone matches booking's phone
  const { data: profile } = await admin
    .from('profiles')
    .select('phone')
    .eq('id', user.id)
    .single();
  
  if (!profile?.phone || profile.phone !== booking.client_phone) {
    // Phone mismatch — require OTP
    throw new Error('PHONE_MISMATCH_REQUIRES_OTP');
  }
  
  // 3. Safe to link
  await admin.from('bookings')
    .update({ client_id: user.id })
    .eq('id', bookingId)
    .is('client_id', null);
  
  // 4. Audit log
  await admin.from('link_attempts').insert({
    booking_id: bookingId,
    user_id: user.id,
    result: 'success',
    ip: await getClientIP(),
  });
}
```

**Solution (Option B: Signed magic link — gold standard):**
- Generate `link_token` on booking creation (store in `bookings.link_token`, TTL 15min)
- Send via SMS to `bookings.client_phone`
- User clicks link → token validated → link auto-occurs

**Required new infrastructure:**
- New table: `link_attempts` (booking_id, user_id, ip, user_agent, result, ts)
- Index on `(booking_id, ts)` and `(user_id, ts)`
- RLS: only admin client can read/write

**Migration file:** `139_booking_link_security.sql`

```sql
CREATE TABLE IF NOT EXISTS public.link_attempts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  booking_id UUID NOT NULL REFERENCES public.bookings(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
  ip INET,
  user_agent TEXT,
  result TEXT NOT NULL CHECK (result IN ('success', 'phone_mismatch', 'not_found', 'already_linked', 'rate_limited')),
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_link_attempts_booking_id ON public.link_attempts(booking_id, created_at DESC);
CREATE INDEX idx_link_attempts_user_id ON public.link_attempts(user_id, created_at DESC);
ALTER TABLE public.link_attempts ENABLE ROW LEVEL SECURITY;
-- No policy = only service_role can access
```

**E2E tests required:**
- Attacker tries to claim another user's booking → blocked
- User with matching phone → success
- Rate limit (5 attempts per 15min)

import { timingSafeEqual } from 'node:crypto';
function verifyCronSecret(authHeader: string | null): boolean {
  const expected = process.env.CRON_SECRET;
  if (!expected || !authHeader) return false;
  const [scheme, token] = authHeader.split(' ');
  if (scheme !== 'Bearer' || !token) return false;
  const a = Buffer.from(token);
  const b = Buffer.from(expected);
  if (a.length !== b.length) return false;
  return timingSafeEqual(a, b);
}
