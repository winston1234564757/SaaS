**Зміст нового Studio блоку:**

## Кроки виконання

### Фаза 1: Аудит поточного стану
1. `Read BillingPage.tsx` — побачити поточний дизайн і тексти
2. `Read XDEV/BOOKIT.md` (секція тарифів) — звірити ціни і ліміти
3. Оновити опис Pro тарифу якщо застарів

### Фаза 2: Studio блок
1. У `BillingPage.tsx` — знайти Studio секцію
2. Замінити на "В розробці" блок з формою бета-заявки
3. `humanizer` для всіх текстів:
   - Заголовок
   - Підзаголовок
   - CTA кнопка
   - Success message

### Фаза 3: Backend для заявок
1. Міграція: `CREATE TABLE beta_requests (id uuid, name text, contact text, business_type text, created_at timestamptz)`
2. RLS: INSERT для анонімних (або auth), SELECT тільки для service_role
3. Server Action `submitBetaRequest` → INSERT + відправити email/TG notification адміну
4. `mempalace_add_drawer` після міграції

### Відкриті питання (QA Gate перед кодом)
