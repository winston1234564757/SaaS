# BookIT — Профіль Продукту (Investor & Partner Brief)

> **BookIT** — це провідна українська SaaS-платформа для автоматизації сервісного бізнесу.  
> *"Ми перетворюємо 'Link in Bio' на повноцінний автономний бізнес-акселератор."*  
> **Версія системи:** v6.5 "Bento Analytics & CRM Intelligence"  
> **Оновлено:** 14 травня 2026 року

---

## 🎯 Візія та Ринок

BookIT вирішує проблему хаотичного управління для мікро- та малого сервісного бізнесу (б'юті, медицина, консалтинг, індивідуальне навчання). Платформа замінює розрізнені інструменти (Instagram DM, Excel, паперові нотатники) єдиною екосистемою, яка працює на випередження.

**Цільова аудиторія:**
- **Solo Masters:** Незалежні фахівці, що цінують власний бренд та час.
- **Boutique Studios:** Команди до 10 майстрів, що потребують централізованого управління без зайвої складності.

---

## 🏗️ Архітектура Рішення

Система побудована за принципом "Dual-Zone Architecture":

### 1. Master Zone (Command Center)
Повноцінна ERP/CRM система для власника бізнесу, доступна як Progressive Web App (PWA).
- **Dashboard & Analytics:** Bento-сітка з миттєвим оглядом дня, виручки та завантаженості.
- **Smart Schedule:** Динамічне управління часом з урахуванням відпусток, перерв та складних багатоетапних послуг.
- **CRM Intelligence:** Автоматичне сегментування клієнтів (VIP, Regular, New, At Risk) на основі LTV та частоти візитів.

### 2. Client Zone (Premium Booking Experience)
Публічна сторінка майстра, оптимізована для максимальної конверсії з соціальних мереж.
- **Booking Wizard:** 6-кроковий інтерфейс з нульовим тертям, що працює без обов'язкової реєстрації (SMS OTP guest flow).
- **Retail & Portfolio:** Вбудований магазин товарів та галерея робіт з підтвердженням від клієнтів.
- **My Area:** Особистий кабінет клієнта для відстеження записів, прогресу в програмі лояльності та історії покупок.

## 💎 Ключові Технологічні Переваги

### 🧠 Smart Slots Engine
Унікальний алгоритм генерації доступного часу, який:
- Запобігає появі "мертвих зон" (Fluid Anchor).
- Підтримує **Multi-service bookings** (автоматичний підбір послідовних слотів).
- Інтегрує **Dynamic Pricing**: автоматичні націнки у пікові години та знижки на "гарячі слоти" (Early Bird / Last Minute).

### 📣 Marketing Hub & Broadcasts
Автономний маркетинговий відділ у смартфоні:
- **Story Generator:** Миттєве створення професійного SMM-контенту з вільними вікнами.
- **Cascade Delivery:** Розумна доставка сповіщень через In-App → Web Push → Telegram → SMS fallback.
- **Targeted Broadcasts:** Персоналізовані розсилки по сегментах CRM з трекінгом конверсії в реальний запис.

### 📦 Inventory Intelligence
Повноцінний ритейл-модуль:
- Синхронізація залишків при продажу через Booking Wizard або прямі замовлення.
- Рекомендації товарів до конкретних послуг (Cross-sell).
- Інтеграція з **Новою Поштою** для доставки за межі студії.

## ⚙️ Технологічний Стек (State-of-the-Art)

| Шар | Технологія | Переваги |
|---|---|---|
| **Frontend** | Next.js 16 (App Router) | Максимальна швидкість завантаження (SSR/ISR) та SEO-оптимізація. |
| **Runtime** | React 19 + Turbopack | Найсучасніша база для стабільної роботи інтерфейсу. |
| **Backend** | Supabase (PostgreSQL) | Надійність корпоративного рівня, Realtime-оновлення та RLS-безпека. |
| **UI/UX** | Framer Motion + Tailwind v4 | Преміальна естетика (Blossom Atmosphere), плавні анімації та Mica-ефекти. |
| **Payments** | Monobank (Ed25519) | Безпечний еквайринг, рекурентні платежі та автоматичний Dunning. |
| **Comm** | Web Push API + TurboSMS | Гарантована доставка сповіщень без встановлення додатків. |
