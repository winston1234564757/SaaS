# BookIT — Профіль Продукту (Investor & Partner Brief)

> **BookIT** — це провідна українська SaaS-платформа для автоматизації сервісного бізнесу б'юті-індустрії.  
> *"Ми перетворюємо 'Link in Bio' на повноцінний автономний бізнес-акселератор."*  
> **Версія системи:** v8.2 "Frost, Portfolio Consent & Marketing Hub"  
> **Оновлено:** 24 травня 2026 року

---

## 🎯 Візія та Ринок

BookIT вирішує проблему хаотичного управління для мікро- та малого сервісного бізнесу (б'юті, косметологія, індивідуальні послуги). Платформа замінює розрізнені інструменти (Instagram DM, Viber, паперові нотатники, Excel) єдиною екосистемою, яка працює на випередження.

**Цільова аудиторія:**
- **Solo Masters:** Незалежні фахівці б'юті-індустрії, що цінують власний бренд, естетику та час. Телефон є їхнім офісом, додаток використовується mobile-first у коротких перервах.
- **Boutique Studios:** Малі команди та студії (від 2 до 10 майстрів), які потребують централізованого управління розкладом, per-master аналітики та професійної публічної сторінки.

## 🏗️ Dual-Zone Architecture (Двозонна Архітектура)

Система побудована за принципом розподілу на дві зони взаємодії:

### 1. B2B Master Zone (Command Center)
Повноцінна ERP/CRM система для власника бізнесу, розроблена за концепцією **Dashboard Editorial (Kinfolk + Aesop + Monocle)**.
- **Bento Dashboard:** Асиметрична мозаїчна сітка (Identity, Intelligence, Action, Metrics), яка дає змогу оцінити стан дня за 3 секунди без скролінгу. Усі налаштування та CRUD-операції додаткових інструментів (флеш-акції, смарт-ціни, лояльність, реферали, партнери) здійснюються через преміальні перемикачі вкладок (Tabs Switcher) безпосередньо на сторінках Revenue та Growth Hubs, що прибирає зайві переходи та модальні вікна.
- **Smart Schedule:** Динамічне управління часом з урахуванням відпусток, перерв та складних багатоетапних послуг.
- **CRM Intelligence:** Автоматичне сегментування клієнтів (VIP, Regular, New, At Risk) на основі LTV, тегів та частоти візитів за допомогою RPC `get_master_clients_with_vip`.
- **Marketing Hub:** Панель управління маркетинговими кампаніями (Story Generator, targeted broadcasts).
- **Portfolio & Products Manager:** CRUD-інтерфейси для управління кейсами робіт, завантаження фотографій з drag-reorder та товарного складу з контролем залишків.

### 2. B2C Client Zone (Premium Booking Experience)
Публічна сторінка майстра `/[slug]`, оптимізована для максимальної конверсії з Instagram/TikTok з використанням ефектів Glassmorphism та атмосферного тла (Blossom, Studio, Frost).
- **Booking Wizard:** Швидкий 6-кроковий інтерфейс запису без обов'язкової реєстрації (SMS OTP guest flow з віртуальними поштами `phone@bookit.app`).
- **Public Shop (`/[slug]/shop`):** Каталог товарів майстра з кошиком та формою оформлення замовлення (pickup або доставка Новою Поштою).
- **Public Portfolio Gallery (`/[slug]/portfolio`):** Галерея виконаних робіт з детальною інформацією про послуги та відгуки клієнтів.
- **My Area (`/my/`):** Особистий кабінет клієнта для відстеження записів, прогресу програми лояльності та підтвердження згоди на публікацію робіт (Portfolio Consent Flow).

## 💎 Ключові Інтелектуальні Модулі системи (v8.2)

### 🧠 1. Smart Slots & Dynamic Pricing Engine
Унікальний алгоритм генерації та розрахунку вартості доступного часу:
- **Fluid Anchor:** Запобігає появі "мертвих зон" у розкладі, притискаючи слоти один до одного або до перерв.
- **Multi-service Bookings:** Автоматичний підбір та прорахунок послідовних часових слотів для декількох послуг за один візит.
- **Dynamic Pricing:** Автоматична коригування цін у копійках на основі правил (націнки у піковий час, знижки на "гарячі слоти" Early Bird / Last Minute). Межі коригування: floor -30%, ceil +50%.

### 🔒 2. Portfolio Consent Flow (Юридична Безпека)
Унікальна для ринку система легальної публікації фотографій робіт клієнтів:
- Майстер створює роботу у кабінеті (`portfolio_items`), завантажує до 5 фото та посилається на візит клієнта.
- Клієнту автоматично надходить сповіщення (Push/Telegram) із запитом на згоду.
- Клієнт у своєму кабінеті `/my/notifications` може переглянути фото та обрати: **Approve** (публікація дозволена) або **Decline** (публікація заблокована).
- Робота автоматично публікується у галереї майстра тільки після статусу `approved`.

### 📦 3. Retail & Inventory Intelligence
Інтегрований модуль товарного ритейлу для додаткового доходу майстра:
- **Stock Control:** Автоматичне списання залишків товарів (`decrement_stock_rpc`) при покупці через кошик або запис.
- **Stock Alert:** Надсилання сповіщення `notifyMasterStockAlert` майстру, якщо кількість товару опускається нижче порогу `stock_alert_threshold`.
- **Nova Poshta Integration:** Підтримка поштової доставки з вказанням адрес та автоматичним розрахунком доставки (контролюється полем `ships_nova_poshta` у профілі майстра).
- **Cross-sell Recommendations:** Рекомендація супутніх товарів безпосередньо під час запису на послугу на основі зв'язків `product_service_links`.

### 📣 4. Marketing Hub & Targeted Broadcasts
Автономна система утримання та повернення клієнтів:
- **Story Generator:** Конвертер вільного часу в розкладі у візуальний SMM-контент (Stories) для Instagram з можливістю швидкого запису.
- **Targeted Broadcasts:** Сегментовані розсилки (In-App/Push/Telegram/SMS) клієнтам за тегами CRM, LTV чи статусом retention.
- **URL Action Bus:** Система команд через query-параметри URL (`?_action=<type>`), яка дозволяє створювати глибокі посилання (наприклад, `booking:create`).
- **Short Link Bus (`/r/[code]`):** Генерація 6-символьних коротких посилань на акції з персоналізованим трекінгом кліків (`broadcast_links.clicks++`), конверсії в запис та автоматичним застосуванням знижок (`phone_discounts`).

### 🛰️ 5. Notification Cascade & Orchestrator v7.0
Єдина інтелектуальна точка розсилки сповіщень `NotificationOrchestrator.ts`:
- **Каскадування:** `In-App + Push (паралельно) ➔ Telegram ➔ SMS fallback`.
- **SMS Guard:** Тільки 5 критичних подій (`booking_created`, `booking_confirmed`, `booking_cancelled`, `reminder_2h`, `subscription_failed`) мають право надсилати платне SMS. Решта 16 типів подій фізично заблоковані через `sms: null` у реєстрі подій.
- **Adoption Mechanics:** Інтерактивні кроки налаштування каналів після запису (`PostBookingAuth`) та в онбордингу майстра, а також persistent banner `ChannelBanner.tsx` у кабінеті клієнта до моменту підключення безкоштовних каналів (Push та Telegram).
- **Логування:** Запис кожного результату доставки у таблицю `notification_logs`.

### 💳 6. Monobank Billing & Dunning
Еквайрингова система білінгу майстрів:
- **Тарифні плани:** Starter (0 ₴, ліміт 40 записів/міс, вотермарка), Pro (700 ₴/міс, повна аналітика, CRM, Telegram), Studio (від 299 ₴/майстер/міс, робота в команді).
- **Mono Webhook Security:** Строга Ed25519 сигнатурна перевірка запитів банку з ротацією ключів.
- **Dunning Process:** При закінченні підписки запускається щоденне рекурентне списання за збереженим токеном. Якщо списання неуспішне протягом 3-х днів, майстру надається безкоштовний grace period (1 місяць), після чого відбувається автоматичний downgrade на Starter тариф з відправкою сповіщення `notifyMasterBilling`.

## ⚙️ Технологічний Стек (v8.2)

| Шар | Технологія | Роль та Переваги |
|---|---|---|
| **Frontend** | Next.js 16 (App Router) | SSR/ISR для публічних сторінок майстра, швидке завантаження, SEO, JSON-LD структуровані дані. |
| **Compiler** | React 19 + Turbopack | React Compiler увімкнено, миттєвий відгук інтерфейсу. |
| **Backend** | Supabase (PostgreSQL) | RLS безпека на рівні бази даних, RPC функції для аналітики, Realtime підписка на сповіщення. |
| **Styling** | Tailwind v4 | `@import "tailwindcss"` у globals.css, кастомні змінні, Mica-ефекти, три теми інтерфейсу. |
| **Motion** | Framer Motion v12.35.1 | Sliding Tab Indicators via `layoutId`, `mode="popLayout"` для динамічних списків, spring-фізика. |
| **Drawers** | Vaul (BottomSheet) | Нативні мобільні шторки з iOS-handle, підтримка свайпу, ізольовані `?drawer=` параметри. |
| **State** | Zustand v5 + nuqs | Zustand для локального стану інтерфейсу, `nuqs` для URL-state. |
| **Payments** | Monobank API | Рекурентні платежі, безпечний еквайринг, відсутність сторонніх шлюзів. |

## 🔒 Безпека та Privacy
- **Строгий RLS:** Кожна таблиця має активний Row Level Security, прив'язаний до `auth.uid()`.
- **Адмін-клієнт:** `createAdminClient()` використовується виключно в закритих server-side cron та webhook операціях.
- **Захист від перебору OTP:** Advisory lock rate-limit у Supabase RPC `check_and_log_sms_attempt` по номеру телефону та IP.
