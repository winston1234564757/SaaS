# [PLANFICH] "Кешбек" в Loyalty системі — Маркетинг vs Реальність

## Статус
🟡 **Назва/позиціонування не відповідає реалізації**

## Що обіцяно

`LandingBentoFeatures.tsx`:
> "Кешбек — змушує повертатись"
> Bento демо: "🎁 Ваші бали: 380 = 76 ₴"

Це передбачає реальну систему **балів/кешбеку** (накопичені бали = гроші).

## Що реально існує

`loyalty_programs` таблиця реалізує **tier model зі знижкою**:

```typescript
// src/components/public/PostBookingAuth.tsx — рядок 304:
{loyaltyPrograms.map(({ id, targetVisits, rewardValue }) => (
  <div>
    <p>{targetVisits} візитів</p>
    <p>−{rewardValue}%</p>  // ← ВІДСОТКОВА ЗНИЖКА, не бали
  </div>
))}
```

Реальна механіка:
- Майстер налаштовує: "На 5-й візит клієнт отримує -15%"
- Клієнт отримує **разову знижку** на N-й підтверджений візит
- **Немає** накопичення балів
- **Немає** конвертації балів у гроші
- **Немає** балансу балів

## Розсинхрон
| Маркетинг | Реальність |
|---|---|
| "Ваші бали: 380 = 76 ₴" | Немає балів |
| "Кешбек" | Знижка на N-й візит |
| Накопичувальна система | Tier-based відсоток |

## Рівень критичності
🟡 **Середній** — Не є технічним боргом, але маркетингова комунікація вводить в оману.

## Рекомендація
 скоригувати лендінг:
"Знижки за лояльність — N-й візит = X% знижки" замість "Кешбек".
