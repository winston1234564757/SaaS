# Стокові фони для Генератора Сторіс

Сюди кладемо готові фонові зображення для story-едітора (крок «Вигляд» → «Стокові фото»).

## Як додати фон

1. Поклади файл сюди, напр. `face-01.jpg`.
2. Скажи розробнику ім'я файлу + підпис (напр. `face-01.jpg` = «Портрет»).
3. Він зареєструє його в `STOCK_PHOTOS` у
   `src/components/master/marketing/story/storyConstants.ts`
   (id, label, url `/story-bg/face-01.jpg`).

Секція «Стокові фото» в едіторі з'являється автоматично, щойно масив `STOCK_PHOTOS` не порожній.

## Вимоги до файлів

- Формат: JPG (краще) або PNG.
- Пропорції: вертикальні, бажано 1080×1920 (як сторіс).
- Ліцензія: лише власні або стокові з правом комерційного використання.
  Чужі фото без ліцензії = юридичний ризик на проді.
