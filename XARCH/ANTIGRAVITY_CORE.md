## 📱 UX & INTERACTION RULES

- **Native iOS Feel:** Всі мобільні модалки — тільки через `vaul` (`BottomSheet`). Обов'язковий `pb-32` та свайп для закриття.
- **Tactile Feedback:** `active:scale-95 transition-all` для кожного клікабельного елемента.
- **Sticky Actions:** Кнопки "Далі" / "Зберегти" — завжди `sticky bottom-6`.
- **Motion Priority (7/10):** Анімація має скеровувати око. `Framer Motion v12.35.1`. Використовувати `will-change: transform` для GPU.
- **Micro-interactions:** Debounced збереження (500ms) з візуальним індикатором "Зберігаємо...".
- **Zero Empty States:** Завжди скелетони (`Skeleton.tsx`) під час завантаження та красиві Empty States.

## ⚙️ TECHNICAL COMMANDMENTS

- **Data Pipeline:** DB Schema → Server Action → Form → UI. Перевіряти всі шари перед рендером.
- **Auth Guard:** `src/proxy.ts` — єдине місце захисту роутів.
- **State Management:** TanStack Query v5. `isPending` для мутацій, `isLoading` з guard `!!masterId`.
- **Supabase Rules:** 
  - RLS — завжди увімкнений.
  - `createAdminClient()` — тільки для bypass RLS.
  - `getSession()` в `onAuthStateChange` — тільки через `setTimeout(0)`.
- **Efficiency:** 1 читання на файл за задачу. `dir /s /b` заборонено (використовуй PowerShell).
