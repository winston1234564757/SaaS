# Claude Code Prompt: Sequential Booking UI in Wizard

Ти — Senior Frontend Engineer. Твоє завдання — розширити `BookingWizard.tsx` для підтримки послідовних послуг (курсів).

## КОНТЕКСТ
Деякі послуги в BookIT тепер мають `service_type = 'sequential'`. Це означає, що клієнт має забронювати не один візит, а серію (наприклад, 10 сеансів масажу).

## ЗАВДАННЯ

1. **Детекція типу послуги**:
   - При виборі послуги перевіряти `service_type`. Якщо `sequential`, активувати режим "Multi-step Booking".
   - Використовувати `total_steps` для визначення кількості візитів.

2. **UI Вибору дат (Step-by-Step)**:
   - Замість вибору однієї дати, реалізувати послідовний вибір: "Оберіть дату для 1-го візиту", "Оберіть дату для 2-го візиту" і т.д.
   - Після вибору першої дати, автоматично пропонувати наступну через `default_interval_days`, але дозволяти клієнту обрати іншу.
   - Відображати індикатор прогресу: "Крок 3 з 10".

3. **Валідація слотів**:
   - Для кожного обраного кроку перевіряти доступність слотів через існуючий API.
   - Не дозволяти завершити бронювання, поки не обрано всі кроки (або дозволити частково, якщо це передбачено налаштуваннями — для цієї задачі вважаємо, що **всі кроки обов'язкові**).

4. **Інтеграція з `createBooking`**:
   - Оновити пейлоад, щоб він передавав масив об'єктів `{ date, startTime }` замість одиночних значень.
   - Передавати `sequence_number` для кожного кроку.

5. **Aesthetics**:
   - Використовуй Framer Motion для плавних переходів між кроками вибору.
   - Дизайн має відповідати "Premium SaaS" (sage, peach, Mica effects).
   - Ніяких емодзі.

Почни з аналізу `src/components/shared/BookingWizard.tsx` та `useWizardSchedule.ts`.
