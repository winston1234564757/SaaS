# Звіт про аудит: Етап 1 (Конфігурація, документація та початкове налаштування)

## 1. Конфігурація проекту та Next.js
- **reactCompiler: true** увімкнено, що забезпечує автоматичну мемоізацію компонентів під керуванням React 19.
- **HTTP Security Headers** сумісні з Telegram Mini Apps (TMA):
  - `X-Frame-Options` встановлено в `SAMEORIGIN` для дозволу вбудовування інтерфейсу в Telegram.
  - Строгі правила `Content-Security-Policy` дозволяють підключення лише до безпечних джерел (`self`, Supabase, Google Maps, Telegram).
  - Налаштовано HSTS для примусового HTTPS.
- **Redirects**: Застарілі плоскі маршрути (`/dashboard/flash`, `/pricing`, `/loyalty`, `/referral`, `/partners`) коректно перенаправляються на нову URL-параметризацію шторкок (`?drawer=...`), що забезпечує зворотну сумісність.

## 2. Аналіз основних залежностей
- **Next.js & React**: Оновлено до Next 16.2.0 та React 19.2.3 (App Router).
- **Стилізація**: Tailwind CSS v4 (підключається через `@import` в `globals.css` без застарілих файлів конфігурації).
- **Керування станом**: Zustand v5 та TanStack Query v5 (використовує строгий маркер `isPending` для мутацій).
- **Анімації**: Framer Motion v12.35.1 зі строгим типом spring-варіантів.
- **Тестування**: Playwright 1.59.1, Vitest 4.1.0 та pg.

## 3. Проектні карти та інструкції з дизайну
- `SYSTEM_MAP.md` є основним джерелом знань про структуру файлів та схеми БД.
- `UX_STANDARDS.md` впроваджує строгі правила інтерфейсу:
  - **No-Emoji Policy**: Заборона використання емодзі в UI кнопках, заголовках та плашках на користь іконок Lucide React.
  - **Health Rings**: Кольорові кільця навколо аватарів клієнтів (`active` = зелене, `at_risk` = помаранчеве, `lost` = червоне).
  - **Мобільні шторки**: Використання виключно `BottomSheet` (vaul) із підтримкою свайпу.
  - **Українська локалізація**: Обов'язкове використання функції `pluralUk` для відмінювання слів та `parseError` для обробки помилок.
