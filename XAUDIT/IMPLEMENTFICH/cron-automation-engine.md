# [IMPLEMENTFICH] Cron Automation — 5 Автоматичних Процесів

## Статус
💎 **ГОТОВО — 5 Production Cron Jobs, жоден не згадано на лендінгу**

## Що є?

`src/app/api/cron/` — 5 папок:

### 1. `/cron/reminders` — Автонагадування про запис
- Push + Telegram нагадування клієнту перед записом
- Зменшує no-show на ~30-40% (галузева статистика)

### 2. `/cron/rebooking` — Smart Rebooking
- Автоматично нагадує клієнтам, що "давно не були"
- Базується на `retention_cycle_days` кожного майстра
- Канал: Push + Telegram

### 3. `/cron/check-uncompleted` — Автозакриття Записів
- Переводить `pending` записи в `completed` після закінчення слоту
- Щоб майстру не треба вручну "закрити" кожен запис

### 4. `/cron/expire-subscriptions` — Автоспливання Підписок
- Переводить Pro → Starter після закінчення оплаченого місяця
- Блокує доступ до Pro-features

### 5. `/cron/reset-monthly` — Скидання Місячних Лічильників
- Скидає: кількість Flash Deals за місяць, кількість записів Starter
- Виконується 1 числа кожного місяця

## Безпека
Всі cron handlers мають `Authorization: Bearer {CRON_SECRET}` перевірку першим рядком.
