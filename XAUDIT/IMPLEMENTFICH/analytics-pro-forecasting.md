# [IMPLEMENTFICH] Analytics Pro — Повна Бізнес-аналітика з Прогнозуванням

## Статус
💎 **ГОТОВО ДО ВИКОРИСТАННЯ — Повністю реалізована, частково на лендінгу**

## Що є?

`src/components/master/analytics/AnalyticsPage.tsx` — **990 рядків / 53.9 KB**

### Starter (безкоштовно)
- 4 стати за поточний місяць: Записів / Замовлень / Виручка / Клієнтів
- Більше нічого — тільки поточний місяць (locked date range)

### Pro (700₴/міс)
**Retention / Cohort аналіз:**
- Новий vs Постійний (доля повторних клієнтів у %)
- Базований на `retention_cycle_days` який майстер налаштовує в Settings

**Тренди виручки:**
- 6-місячний bar chart виручки (hoverable tooltips)
- **Linear Regression прогноз** наступного місяця (`linearRegression()` утиліта)
- `+%` або `-%` від попереднього місяця

**Розподіл виручки:**
- Послуги vs Товари при записі vs Товари в магазині
- Gradient bar + hover tooltips

**Кращий день тижня:**
- DayOfWeek chart (7 bars) — який день генерує найбільше виручки
- Автоматично підсвічує найкращий

**Мікро-бенто (3 колонки):**
- Середній чек + delta vs попередній місяць
- Годин забронювано
- Джерело: Онлайн / Вручну / Магазин

**Топ Клієнти:**
- Список з виручкою, кількістю візитів, кліком для відкриття ClientDetailSheet

**Топ Послуги:**
- Cross-sell rate per service
- Середній чек по послузі

**Топ Товари** (якщо є `shop_products`)

**CSV-Експорт:**
- `exportAnalyticsCsv(masterId, startDate, endDate)` → завантаження файлу
