## Відкрите бізнес-питання
Вітос: "хз треба глибокий бізнес-аналіз"

Варіанти unit economics:
- **30/місяць** → швидша конверсія в Pro (~2-3 активні тижні)
- **50/місяць** → більше часу user activation, менша конверсія
- **100/місяць** → майже безлімітно для більшості, але є
- **Unlimited Starter + feature gating** → альтернативна монетизація

Рекомендація: **лишити 30** до збору достатньої кількості платежів для аналізу.
