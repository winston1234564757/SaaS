# [TECH_DEBT] Loyalty "Кешбек" — Назва не відповідає реалізації

## Статус
🟡 **МАРКЕТИНГОВИЙ БОРГ — UX Copywriting вводить в оману**

## Симптом

`LandingBentoFeatures.tsx` показує:
```tsx
<h3>Знижки вбивають дохід. Кешбек — змушує повертатись.</h3>
// Демо: "🎁 Ваші бали: 380 = 76 ₴"
```

Слово "Кешбек" та "Ваші бали" передбачають:
- Накопичення балів за кожен візит
- Конвертація балів у гроші або знижку
- Баланс балів у профілі клієнта

## Реальна реалізація

`loyalty_programs` — Tier-model:
```typescript
// PostBookingAuth.tsx — рядок 304:
{loyaltyPrograms.map(({ targetVisits, rewardValue }) => (
  <div>
    <p>{targetVisits} візитів</p>
    <p>−{rewardValue}%</p>  // ЗНИЖКА на певний візит, не бали
  </div>
))}
```

Реальна механіка:
- Майстер налаштовує: "На 5-й візит — -20%"
- Клієнт автоматично отримує знижку на 5-й підтверджений візит
- **Немає** балансу балів
- **Немає** конвертації у гроші
- **Немає** "380 балів"

## Наслідок
Клієнт може відчути себе обманутим коли побачить, що "кешбеку" немає.

## Рекомендація

**Змінити маркетинг:**
```
"Автоматичні знижки за лояльність"  
"N-й візит = X% знижки — нараховується автоматично"
```
